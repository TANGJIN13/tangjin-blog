这个博客的文章全部来自我的 Obsidian 笔记库。这篇教程讲清楚整条链路：**在 Obsidian 里写 → 加几行 frontmatter → 跑一条命令 → 一两分钟后博客上线**，以及分类是怎么选、怎么显示的。

## 一、在 Obsidian 里写笔记

笔记放在 Obsidian 笔记库里（我的库在 `D:\apps\obsidian\note\TANGJIN`），博客项目本身就是库里的一个子目录 `tangjin-blog`，所以写完不需要"搬运"，脚本直接读文件。

要发布的笔记，开头加上这段 frontmatter（YAML）：

```yaml
---
title: "文章标题"
description: "一句话简介，会显示在列表和分享卡片上"
category: article
tags:
  - Obsidian
  - 教程
published: 2026-10-06
---
```

各字段说明：

| 字段 | 必填 | 作用 |
| --- | --- | --- |
| `title` | 是 | 文章标题 |
| `description` | 建议 | 摘要，显示在首页卡片和归档里 |
| `category` | 建议 | **分类**，决定文章出现在哪个分类页 |
| `tags` | 建议 | 标签，可以有多个 |
| `published` | 建议 | 发布日期，不写则用构建日期 |

## 二、分类怎么选，博客上怎么显示

博客目前有 4 个分类，`category` 写**中文名或英文名都可以**，脚本会自动归一化：

| 博客分类 | category 可写 | 适合内容 |
| --- | --- | --- |
| 随笔 | `essay` 或 `随笔` | 日常、感想、碎碎念 |
| 文章 | `article` 或 `文章` | 技术文章、学习笔记（本文就是） |
| 年度总结 | `summary` 或 `年度总结` | 年终回顾、阶段总结 |
| 工具使用 | `tools` 或 `工具使用` | 软件配置、效率工具心得 |

发布后：

- 首页文章卡片的左上角会显示**分类徽章**，点它直接进入对应分类页；
- 顶部导航「分类」里每个分类页会自动收集 `category` 匹配的文章（按标签匹配也算兜底）；
- 如果 `category` 写了不存在的名字（比如 `category: 生活`），脚本会警告并忽略这一行，文章仍然能发布，只是不带分类。

## 三、发布：一条命令

### 方式 A：`publish.sh`（推荐，Windows 用 Git Bash 跑）

```bash
cd D:/apps/obsidian/note/TANGJIN/tangjin-blog
./publish.sh "D:/apps/obsidian/note/TANGJIN/笔记/我的新文章.md"
```

它会：复制笔记到 `src/content/posts/`（frontmatter 原样保留，包括 `category`）→ git 提交 → 推送到 GitHub。

### 方式 B：`publish.cjs`（Node 脚本）

```bash
# 发布单篇
node publish.cjs "笔记路径.md"

# 或批量：把要发布的笔记丢进库里的 _publish 文件夹，然后
OBSIDIAN_VAULT="D:/apps/obsidian/note/TANGJIN" node publish.cjs
```

它会额外做几件转换：`[[双链]]` 转成站内链接、`![[嵌入图片]]` 转成 `/images/...`、`> [!INFO]` 标注块转成引用、删掉 `%%注释%%`。

> 之前 `node publish.js` 一直报错跑不起来，是因为项目是 ES Module 而 `publish.js` 用了 CommonJS 写法，已改名为 `publish.cjs` 修复。

### 发布后发生了什么

```
git push → GitHub Actions（deploy.yml）
        → pnpm build 打包出 dist/
        → rsync 同步到腾讯云服务器
        → Nginx 提供访问
```

push 之后打开仓库的 Actions 页能看到流水线，全程约 1~2 分钟，变绿即上线。

## 四、图片和资源

- 图片放 `public/images/` 里，笔记里用 `![说明](/images/xxx.png)` 引用；
- 如果用 Obsidian 的 `![[图片.png]]` 嵌入写法（方式 B），会自动转成 `/images/图片名`，所以图片文件名要和引用一致。

## 五、常见问题

**Q：忘了写 category 会怎样？**
文章正常发布，只是卡片上没有分类徽章，分类页里找不到它。随时补一行 `category: xxx` 再发布一次即可。

**Q：已发布的文章想改？**
直接改 Obsidian 里的原笔记，重新跑一遍发布命令，脚本会覆盖同名文件并推送。

**Q：手机上能看到效果吗？**
能，博客对手机端做过适配。如果样式没变化，先强制刷新一次（或清缓存），Nginx 对 HTML 已设置为不缓存。
