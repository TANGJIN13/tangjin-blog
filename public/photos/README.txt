相册照片放这里
============

1. 把你的照片（jpg / png / webp 等）复制到这个 public/photos/ 文件夹里。
2. 打开项目里的 src/data/album.json，按下面的格式增删条目：

   {
     "src": "/photos/你的照片.jpg",   // 相对 public 目录的路径
     "title": "照片标题",
     "date": "2026-10-01",            // 用于排序，新的在最前
     "location": "拍摄地点（可选）",
     "desc": "一句话描述（可选）"
   }

3. 保存后站点会自动重新构建并部署。

提示：album.json 里现在的前几张是占位示例图，替换成你的真实照片即可。
