# 发布配置说明

> 一次性配置。配好之后，写文章只需要在 `/admin/` 点一次「发布」。

---

## 整条链路长什么样

```
你在 /admin/ 写文章
        ↓  点「🚀 发布」
   GitHub API 提交 md 文件
        ↓
   GitHub 仓库 main 分支
        ↓  自动触发
   GitHub Actions（在 GitHub 的机器上构建）
        ↓  rsync
   你的服务器 /var/www/blog
        ↓
   https://tangjin.xyz 生效（约 1-2 分钟）
```

服务器**不承担构建**，只接收构建好的静态文件，所以 2G 内存完全够用。

## 你需要做的三件事

### 第 1 件：创建 GitHub 仓库

访问：https://github.com/new

| 字段 | 值 |
|---|---|
| Repository name | `tangjin-blog` |
| 可见性 | **Private（私有）** ← 推荐，源码不必公开 |
| 初始化选项 | **全部不勾**（不要 README / .gitignore / License） |

创建后得到仓库 `TANGJIN13/tangjin-blog`。

> 如果仓库名不是 `tangjin-blog`，需要同步改三处：
> - `.github/workflows/deploy.yml` 里的 `SSH_HOST` 无关，但 `public/admin/index.html` 里的 `gh_repo` 默认值
> - `public/admin/index.html` 里「部署状态」按钮的链接

### 第 2 件：把本地代码推上去

在本机项目目录执行（把 `你的仓库地址` 换成实际地址）：

```bash
cd tangjin-blog
git remote add origin https://github.com/TANGJIN13/tangjin-blog.git
git push -u origin main
```

### 第 3 件：添加部署密钥（GitHub Secret）

1. 打开仓库 → **Settings** → **Secrets and variables** → **Actions**
2. 点 **New repository secret**
3. Name 填：`SSH_PRIVATE_KEY`
4. Secret 填：**本机这个文件的完整内容**（包括首尾的 `-----BEGIN/END-----` 两行）

```
C:\Users\liang\Documents\deepseek-harness\default-workspace\deploy-key\github-actions-deploy
```

> 这个密钥是**专门为部署生成的**，和你的 `ssh tangjin` 登录密钥无关。
> 万一泄露，删掉服务器 `~/.ssh/authorized_keys` 里对应那行即可失效。

## 写文章怎么用

1. 打开 https://tangjin.xyz/admin/
2. 点 **⚙️ 设置**，填入 GitHub Token（见下方「Token 怎么来」）
3. 点 **+ 新建文章**，填标题/描述/标签，写正文
4. 点 **🚀 发布** → 等 1-2 分钟自动上线

### Token 怎么来

访问 https://github.com/settings/tokens

- 选 **Fine-grained token**（更安全）或 **Classic token**
- 权限：只需要对 `tangjin-blog` 这一个仓库的 **Contents: Read and write**
- 有效期：建议设长一点，过期后重新生成填进去即可

Token 保存在浏览器 `localStorage` 里，**不会上传到任何服务器**。

## 平时写文章（不用后台的备用方案）

```bash
# 在 src/content/posts/ 里新建 .md 文件
# 然后：
deploy.cmd          # 双击即可：本地构建 + 直接传到服务器
```

或者推 GitHub 让 Actions 自动部署：

```bash
git add .
git commit -m "post: 新文章"
git push
```

## 出问题怎么查

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面 403 | 目录权限不是 755 | 服务器执行 `find /var/www/blog -type d -exec chmod 755 {} +` |
| Actions 失败 | 缺 `SSH_PRIVATE_KEY` | 见上面第 3 件 |
| admin 发布报 401 | Token 过期或权限不足 | 重新生成 Token |
| admin 发布报 404 | 仓库名填错 | 后台「设置」里改仓库名 |
| 改了没生效 | Actions 还在跑 | 去仓库 Actions 页面看进度 |
