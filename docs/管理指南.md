## 1. 如何修改站点配置

**修改 `src/site.ts`**：

```ts
export const site = {
  title: 'tj',                    // 导航栏名字
  tabTitle: "tj's Blog",          // 浏览器标签标题
  motto: '凡心所向，素履以往',     // 首页大字
  icp: '桂ICP备2026005024号-1',   // 备案号
  startDate: '2026-10-04',         // 建站日期
  footer: { since: 2026 },         // 页脚起始年
};
```

**改完怎么上线**：
1. 打开 https://github.com/TANGJIN13/tangjin-blog
2. 点 `src` 文件夹 → 点 `site.ts` 文件
3. 点右上角 ✏️ 铅笔图标
4. 改内容
5. 往下滚，点绿色 **Commit changes** 按钮
6. 等 1-2 分钟自动上线

## 2. 如何写文章

### 通过 GitHub

1. 打开 https://github.com/TANGJIN13/tangjin-blog/tree/main/src/content/posts
2. 点 **Add file** → **Create new file**
3. 文件名：`YYYY-MM-DD-标题.md`（如 `2026-10-05-我的新文章.md`）
4. 内容：

```markdown
---
title: "我的新文章"
description: "一句话摘要"
published: 2026-10-05
category: web-security
tags: ["Web安全", "XSS"]
cover: /images/my-cover.png  # 可选，封面图
---

正文用 **Markdown** 写。

## 二级标题

- 列表项
- 列表项

\`\`\`python
print("代码块")
\`\`\`
```

5. 点 **Commit changes** → 等 1-2 分钟上线

### 文章字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | ✅ | 标题 |
| `description` | ✅ | 摘要（显示在卡片和文章头）|
| `published` | ✅ | 发布日期 |
| `tags` | ❌ | 标签数组 |
| `draft` | ❌ | `true` 则不发布 |
| `cover` | ❌ | 封面图路径（相对 public/）|
| `category` | ❌ | 分类 slug |

## 3. 如何管理友链

**修改 `src/pages/friends.astro`**，找到 `friends` 数组：

```ts
const friends: Friend[] = [
  { name: 'C1everF0x', url: 'https://c1everf0x.cn/', avatar: 'https://...', description: 'Web 安全 / CTF 选手' },
  // 加友链：复制上面一行，改内容
  { name: '朋友名字', url: 'https://朋友网址/', avatar: '头像图片链接', description: '一句话介绍' },
];
```

**删除友链**：删掉对应那行。

**改完**：Commit → 等 1-2 分钟上线。

## 4. 如何管理分类

**修改 `src/data/categories.ts`**：

```ts
export const categories: Category[] = [
  { name: 'Web 安全', slug: 'web-security', icon: 'lock' },
  { name: 'CTF', slug: 'ctf', icon: 'flag' },
];
```

- `name`：显示的名字
- `slug`：网址用（英文/数字/连字符）
- `icon`：Icon 组件里的图标名

**加分类**：加一行。**删分类**：删那行。

## 5. 如何添加音乐

1. 把音乐文件复制到 `public/music/` 文件夹
2. 打开 https://github.com/TANGJIN13/tangjin-blog/blob/main/src/components/MusicPlayer.astro
3. 找到 `tracks` 数组，加一行：

```ts
const tracks = [
  { name: '我走后', artist: '小咪', url: '/music/wo-zou-hou.mp3', cover: '/images/music-cover.svg' },
  { name: '新歌名', artist: '歌手名', url: '/music/文件名.mp3', cover: '/images/music-cover.svg' },  // ← 加这行
];
```

4. 点 **Commit changes** → 等 1-2 分钟上线

## 10. 常见问题

### 改完没生效？
- 浏览器缓存：`Ctrl + Shift + R` 强刷
- GitHub Actions 还在跑：等 1-2 分钟，去 https://github.com/TANGJIN13/tangjin-blog/actions 看进度

### 页面 404？
- 检查文章文件名格式：`YYYY-MM-DD-标题.md`
- 检查 frontmatter 格式：`---` 开头结尾，`published: YYYY-MM-DD`

### 构建失败？
- 去 GitHub Actions 看错误信息
- 常见原因：YAML 格式错、文件名拼写错、缺少必填字段

### 想本地预览？
```bash
cd tangjin-blog
pnpm install
astro dev --background
# 打开 http://localhost:4321
```
